## 💗 About

This project is a lightweight calculator built with web technologies, focused on clarity, usability, and visual warmth.

The goal was to create something:

- ✨ **Easy to use** – Intuitive interface for everyone
- 🎀 **Visually pleasant** – Soft colors and welcoming design
- 🚀 **Functional without complexity** – Simple yet effective
- 🧁 **Perfect for small businesses** – Ideal for bakeries and cozy shops

---

## 🌟 Features

- 🎨 **Clean and minimal UI**
- 💖 **Soft pink visual style**
- 📱 **Responsive layout**
- 🧮 **Simple and intuitive logic**
- ⚡ **Lightweight and fast**
